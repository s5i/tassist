Sessions

  • Start starts a "session" that tracks the experience gained and time elapsed.
  • Stop and Reset clear the session stats.
  • Pause temporarily freezes the session; experience changes and time elapsed while paused are not counted towards session stats.

Exp detection

  • TAssistant only attempts to detect exp while the session is running.
  • For exp detection to work, the Skills tab needs to be open with the Experience line being fully visible.
  • If exp detection is not working despite an active session, try re-focusing the game window (eg. by alt-tabbing into another window and back).
  • How do we detect experience?
    • We take a screenshot of a window matching the OT-specific window title.
    • We find the Experience label in the rightmost 200 pixels of the screenshot.
    • We run OCR on the 80x10 box right of the Experience label.
    • We repeat this process every second.
  • Store stores the account that's currently saved by the game client.
  • Clicking an entry restores a previously stored account.
  • Rename allows you to rename a stored account.
  • Delete removes a stored account.
  • The game client refreshes the stored account on each character login; keep this in mind to avoid confusion around which account is stored/loaded.
  • How does this work?
    • The game client keeps the (encrypted) credentials in Windows Registry.
    • When storing an account, we copy the relevant registry keys into %AppData%\TAssistant\accounts.yaml.
    • When loading an account, we restore the relevant registry keys.
  • Loop controls whether the timer should automatically start ticking again after it fires.
  • Sound controls whether the timer should beep when firing.
  • AutoAck automatically dismisses the timer when it fires; if sound is enabled, the beep will play once.
  • You can dismiss a firing timer by clicking on it.
  • The timers are preserved even if the application is not running.
  • If there are timers firing at startup time, the sound will not play.
  • You can replace the beep sound by placing a beep.mp3 file in the %AppData%\TAssistant directory and restarting TAssistant.
