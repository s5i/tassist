Hunt

World

  • Online displays the number of players online on the chosen world.
  • Ping displays your round-trip-time to the chosen world.
  • Packet loss displays the percentage of ping packets lost within the last 20 seconds.

Experience Tracker

  • You need to have the Skills tab open with the "Experience" line being visible.
  • If exp detection is not working despite an active session, try re-focusing the game window (e.g. by alt-tabbing into another window and back).
  • Level and Experience display the current level and experience, respectively.
  • Remaining displays the experience needed to reach the next level.
  • Session exp/h, Session exp, Session duration display the experience per hour, gained experience, and time elapsed since the session started, respectively.
  • Start/Stop: controls whether the session is active.
  • Pause/Unpause controls whether the session is paused; while paused, neither experience changes nor time elapsed is counted towards exp/h.
  • Reset resets the session.

Accounts

  • Store stores the current saved credentials.
  • Load restores previously stored credentials.
  • Double-clicking an entry allows you to rename it.
  • The game client refreshes the stored credentials on each character login; keep this in mind to avoid confusion around which credentials are stored/loaded.

Timers

  • Loop controls whether the timer should automatically start ticking again.
  • Sound controls whether the timer should beep when firing.
  • You can dismiss a firing timer by clicking on it.
  • The timers are preserved even if the application is not running.
  • If there are timers firing at startup time, the sound will not play.

Settings

  • Clicking on a world name will reload TAssistant with settings tuned to a given world (players online, server IPs, client window name, etc).

Technical details

  • The application quits automatically ~15-20 seconds after closing the browser tab.
  • Online numbers are pulled from tibiantis.info and opentibia.info.
  • Experience tracking: TAssistant takes a screenshot of a window matching the OT-specific window title every 2 seconds, searches for "Experience" on the right panel, and then runs OCR on the line.
  • Account switching: TAssistant stores the Base64-encoded registry entries under %AppData%\TAssistant\accounts.yaml.
  • Packet loss measure: If a server uses built-in proxies, we display the average across all known proxies.
